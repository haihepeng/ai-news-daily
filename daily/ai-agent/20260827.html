架构观点：Agent 应该'持久'而非'长寿'

#Agent 架构 #基础设施 #工程实践 · 来源：

文章提出 Agent 架构的关键区分：将'Agent 运行'与'执行它的进程'分离。Agent 运行是持久的——状态、消息、工具结果、预算和当前位置存储在 worker 之外；worker 是临时的，租赁一个可运行的 Agent、短时工作、检查点新状态后消失。关键的边界是'等待'：Agent 需要等 CI 五分钟时不应睡眠五分钟，而是记录等待状态后退出，待任务完成或定时器触发再恢复运行。

推荐理由：面向生产环境的 Agent 基础设施设计思路，解决长任务可靠性问题，对 Agent 平台建设者有直接启发。
