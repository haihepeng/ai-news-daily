Auto：用WASM二进制文件编译LLM Agent行为，实现 microdollars 级推理成本

#AI Agent #WASM #成本优化 #编译器 #GitHub开源 · 来源：GitHub Trending

Auto 是 RightNow AI 开发的一个 AGI 编译器，能够将 LLM Agent 的执行行为记录下来，证明哪些部分是可重复的，然后编译成经过验证的、 sandboxed WASM 二进制文件。核心思路是将前沿模型当作解释器，构建一直跟在解释器后面的编译器。实测显示，边际成本从每项约 59 微美元降至约 2 微美元，降幅达 30 倍。该项目基于 arXiv:2607.04542 论文，采用 Apache-2.0 开源协议。

推荐理由：Auto 代表了 AI Agent 成本优化的重要方向。对于 AI 基础设施工程师和 Agent 开发者而言，其「ratchet」设计——确保没有重复计算——具有重要的参考价值。建议了解其技术实现细节和适用场景。

Clay Seal：为 AI Agent 运行时安全而生的控制平面

#AI Agent #安全控制 #权限管理 #零信任 #开源 · 来源：Show HN

Clay Seal 是一个 AI Agent 的运行时权限控制平面。与传统基于 API Key 或 OAuth scope 的静态权限不同，Clay Seal 在每个操作执行时进行检查，如果 Agent 开始执行不该做的操作，下一个操作会被阻止。系统包含三个部分：Runtime Authority（单次操作批准）、Attested Identity（身份验证）和 Verifiable Receipts（可验证记录）。基于开放标准构建，包括 SPIFFE、SID、 Biscuit tokens 等。

推荐理由：Clay Seal 解决了一个关键问题：Agent 在会话中期可能被诱导滥用权限。对于构建企业级 AI Agent 系统的开发者，Clay Seal 提供了有价值的参考架构。建议了解其技术实现细节。
