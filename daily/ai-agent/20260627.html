Neo4j 首席科学家 Jim Webber 提出三层 Agent 记忆模型：长期记忆（企业知识/ground truth）、短期记忆（会话历史/实时编排）、推理记忆（决策轨迹/可解释性）。上下文图通过图数据库实现这三层记忆的统一查询，解决当前 agent 因记忆受限导致的计划遗忘、目标漂移等问题。

推荐理由：为构建可靠的生产级 agent 提供了清晰的记忆架构蓝图，Neo4j Agent Memory 开源库可直接用于 LangChain、LlamaIndex 等主流框架。

#模型路由 · #成本优化 · #开源 · 来源：GitHub - WorkWeave

Topos：用结构化指标评估 Agent 生成代码的质量

#代码质量 · #Agent评估 · #开源 · 来源：Krv Labs

Krv Labs 推出 Topos 开源框架，将代码审查从逐行 diff 转向可验证的结构属性。通过将代码解析为数学图（AST、CFG、CPG、MDG），基于三个独立维度（简单性、可组合性、安全性）评估质量，生成金牌/银牌/铜牌/垃圾四级评分，解决 agent 生成代码的'绿色疲劳'问题。

推荐理由：为 agent 代码质量评估提供了客观、可量化的标准，VS Code 插件和 MCP 服务器可直接集成到开发工作流中。

Hush：让 AI Agent 使用密钥但永远看不到明文

#Agent安全 · #密钥管理 · #开源 · 来源：GitHub

Hush 是一个跨平台密钥存储工具，核心规则是 agent 永远看不到密文明文。密钥存储在 OS 钥匙串中，通过命令注入使用，值永远不会进入 stdout、转录或云端。支持 macOS Keychain、Linux libsecret、Windows DPAPI，MIT 开源。

推荐理由：解决了 agent 安全领域的关键痛点——密钥管理，设计简洁但有效，可直接集成到 Claude Code 等 agent 工作流中。

用 JSON 替代截图：优化编码 Agent 的输入方式

#编码Agent · #输入优化 · #Token节省 · 来源：SlimSnap

SlimSnap 提出用结构化 JSON 替代截图作为编码 agent 的输入，token 消耗降低 55-85%（从 ~4784 降至 ~700 tokens）。JSON 包含元素 ID、类型、边界框、颜色和 OCR 文本，通过注解系统消除了 agent 对截图的猜测，开源 schema 标准确保工具无关性。

推荐理由：为编码 agent 的输入优化提供了实用方案，token 节省在长会话中尤其有价值，开源 schema 标准值得前端团队关注。
