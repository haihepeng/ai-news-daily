Wiz 自主 AI 安全代理发现 GitHub Copilot Autofix 引入的 CI/CD 注入漏洞，渗透 Snowflake 内部系统

#AI 安全 #Wiz #Snowflake #自主代理 #CI/CD · 来源：

Wiz 研究团队的自主安全代理 Red Agent 在 Snowflake 的公开仓库中发现了一个 GitHub Actions 脚本注入漏洞：一条由 Copilot Autofix 生成的提交删除了原有安全的 env 变量 + jq 解析模式，改为直接字符串拼接 issue 标题，攻击者只需打开一个精心构造标题的 issue 即可在 runner 上执行任意命令。Red Agent 完全自主地发现并利用该漏洞，在解析报错后自主调整 payload，最终通过 out-of-band 回调窃取了 Snowflake 内部 Jira 的凭证，验证了对工程、安全合规及漏洞赏金项目的读取权限。漏洞仅存活 5 天即被 AI 代理发现并验证。

推荐理由：AI 生成的代码引入安全漏洞 + AI 代理自主发现并利用，双重里程碑事件，标志着 AI 安全攻防进入全自动化时代。
