#上下文层 #MCP #数据目录 #开源 #AI基础设施 · 来源：news.ycombinator.com

Marmot 是一款开源上下文层（Context Layer），帮助 AI Agent 发现和理解企业内部的数据资产。它能编目所有服务、API、队列、数据库和流水线，并通过 MCP 协议将结构化上下文暴露给 AI Agent 和工程团队。内置 MCP 服务器，支持自然语言查询数据目录。项目由曾在 HashiCorp、Kubernetes 等核心开源项目工作的工程师团队打造，MIT 开源协议。

推荐理由：解决 AI Agent 最核心的上下文获取问题，从硬编码转向动态目录。架构清晰，团队背景强大，MCP 原生支持是加分项。适合需要让 Agent 理解企业数据资产的团队参考。

#Agent记忆 #MCP #认知架构 #开源 #记忆基础设施 · 来源：news.ycombinator.com

AI Agent 完成三分之一的工作：基准测试揭示的可靠性数学

#可靠性 #基准测试 #Agent评估 #半衰期理论 #深度分析 · 来源：news.ycombinator.com

深度分析文章。核心发现：最强 AI Agent 在现实任务中仅完成约 30%（CMU TheAgentCompany 基准）。关键数学原理：即使单步 95% 可靠，20 步任务的完成率仅 36%（0.95^20）。Oxford 的 Toby Ord 提出 Agent 成功的「半衰期」概念。METR 测量显示 Agent 50% 时间线在指数增长，但 80% 时间线比 50% 短约 5 倍。结论：Agent 在窄任务上可靠，在开放多步任务上仍不可靠。

推荐理由：对 Agent 可靠性的量化分析极为重要，揭示了「demo 可靠但生产不可靠」的根本原因。任何构建 Agent 系统的团队都应阅读此文。

#ML编译器 #GPU内核 #系统优化 #Triton #深度分析 · 来源：news.ycombinator.com

深度分析文章。核心论点：AI Agent 已能自主编写和优化 GPU 内核（Meta KernelEvolve 将推理吞吐提升 60%，NVIDIA AVO 超越 cuDNN 3.5%），但 ML 编译器反而更加必要而非过时。原因：组合爆炸问题（多模型×多硬件×多数据类型）、正确性保证需求、跨平台可移植性。结论：Agent 与编译器应在中间层汇合，Triton 是典型代表。Qualcomm 39 亿美元收购 Modular（Mojo）印证了这一趋势。

推荐理由：对 AI Agent 在底层系统优化领域能力边界的深度思考，揭示了 Agent 与传统编译器的互补关系。适合系统级 Agent 开发者阅读。
