HALO：递归自优化的 Agent 循环优化器

Agent 自优化领域的前沿开源工具，解决了从单 trace 学习到系统级改进的关键问题。

开源工具 HALO（Hierarchical Agent Loop Optimization）使用 RLM（递归语言模型）构建自优化的 Agent 系统。核心洞察：通用编码 harness 往往对单个 trace 过拟合，HALO 通过专门的 RLM 工具包观察系统级 Agent 行为并泛化改进。包含桌面应用（ElectroBun/React）和 Python SDK/CLI，支持 OpenTelemetry 追踪和 Langfuse 历史导入。

Linux Foundation 推出 Agent Name Service：AI Agent 的 DNS 身份基础设施

AI Agent 基础设施的里程碑事件，解决了 Agent 身份验证和互操作性的关键缺失环节。

Sherlock Holmes 棋盘游戏作为 LLM Agent 评测：Reasoner+Explorer 架构突破

Agent 架构设计的深刻洞察——角色分离比单纯提升模型能力更有效。

用 Sherlock Holmes Consulting Detective 棋盘游戏评测 LLM Agent 的多步推理能力。Claude Fable 5 在困难模式下与 Holmes 持平。发现两大失败模式：Agent 用自生成内容覆盖检索到的正确事实（可测量的 RAG bug）、Agent 陷入诱饵陷阱。关键发现：分离推理者和探索者的双 Agent 架构（Reasoner+Explorer）成功突破诱饵陷阱，模型能力单独既非必要也非充分。

SAA SDK：语音 Agent 的选择性听觉注意力层

解决语音 Agent 在真实环境中「听谁说话」的关键问题，工程实现完整。

SAA（Selective Auditory Attention）是语音 Agent 的「收件人层」，运行在 STT 之前判断语音是否指向设备，过滤旁白、背景噪音和 Agent 自己的 TTS 输出。无需唤醒词，一次判断一个语句。支持 LiveKit、Pipecat、ElevenLabs、Twilio 等主流语音 Agent 框架。

ask-a-human：Agent 循环中的私密寻呼机

解决 Agent 全自动运行时「需要人类但无法联系」的痛点，设计优雅。

MCP 工具，让全自动运行的 Agent 在需要人类决策时发送加密通知到手机。零配置：复制 MCP JSON 即可使用，无需账号或 API key。端到端加密（SPAKE2 + NaCl），中继服务器仅看到密文。支持 Claude Code、Codex、Cursor 等所有 MCP 兼容 Agent。
