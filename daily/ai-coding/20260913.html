RTK 宣称大幅节省 token，实测成本基准却给出相反结论

#AI编程 #成本优化 #基准测试 #开发者工具 · 来源：

Quesma 团队花费数天、超过 1500 美元 token 成本，对 RTK（Rust Token Killer）做了独立成本基准。RTK 在智能体读取前过滤并压缩终端输出，GitHub 星标已超 7.9 万，一条称其可把 Claude Code token 削减 60% 的推文获得 31.3 万次浏览。但 JetBrains 的 SkillsBench 测试并未发现任何节省，RTK 自己的 README 也声明“削减最多 90% 的 bash 输出”与“账单减 90%”并非同一回事。Quesma 的结论是：终端输出变少可能有效、可能毫无作用，也可能适得其反——因为智能体需要更多轮次，或输出质量下降。文章给出了完整的测量方法与数据。

#AI编程 #产品策略 #行业观察 #软件工程 · 来源：

《纽约时报》9 月 12 日客座评论指出，据一项估算去年苹果 App Store 上架应用数量增长约 30%，但下载量只增长 3%。AI 让制造软件的成本骤降，“由代码构成的一切”突然可以海量供给，可用户并没有等来值得惊叹的新应用或新游戏。作者认为这不算 AI 杀死了杀手级应用，而是方向跑偏：人们不愿为迁移而更换既有工具，AI 真正的机会在于消除生活中大量细碎摩擦，做出更克制、更专用的功能。文章也把部分责任归给 AI 大厂，批评其快速迭代却几乎不提供手册与入门教程，项目失败时又把问题推给使用者不会写提示词。
