研究显示人机协作中人类会漏掉三分之一危险 AI 编码智能体请求

#AI编码 #智能体安全 #人机协作 #权限模型 · 来源：

比利时开发者 Alex Wauters 开发的浏览器游戏收集了超 4 万次运行、40.9 万次批准/拒绝数据，显示人类平均会批准约三分之一的恶意命令请求。最常被漏过的是越权命令（如读取 Kubernetes 配置或 AWS 凭据，漏过率 35%），最容易被漏过的单条命令是 npm run analyze（被批准率近 65%）。反复批准会造成疲劳导致决策草率——Anthropic 数据显示 Claude Code 用户批准约 93% 的权限提示。研究呼吁改进智能体权限模型、使用沙箱和模型分类器，而非单纯依赖人机协作。

推荐理由：用 40 万次真实决策数据量化了人机协作模式的失效，为 AI 编码智能体安全设计提供了关键实证。
