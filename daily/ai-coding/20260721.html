RTK 钩子让编程代理更贵而非更便宜：JetBrains 实测验证

#AI编程 #token优化 #RTK #JetBrains · 来源：JetBrains Blog

JetBrains 对 RTK（Rust Token Killer）这个号称削减 60–90% token 的 CLI 代理做了 151 个任务的系统 A/B 测试。RTK 在 Claude Code 钩子中截获命令输出并压缩，但实测低推理模式下反而多花 7.6% token（p=0.004），高推理模式无差异，任务质量不变。原因是大部分上下文在到达 RTK 前已免费获得。此前 caveman skill 宣传降低 65% 实测仅降 8.5%。

推荐理由：JetBrains 用 151 个配对任务的严格 A/B 测试推翻了 RTK 节省 60–90% 的夸张宣传，实测反而多花 7.6% token，是对 AI 编码工具链营销祛魅的必读分析。

Cognikernel：AI 编程助手的本地持久化记忆

#AI编程 #跨会话记忆 #本地化 #Claude Code · 来源：GitHub

Cognikernel 为 Claude Code 和 Codex 提供持久化项目记忆，通过四个钩子面监控会话，提取决策和约束存入事件溯源存储，下次会话注入紧凑上下文块。独特之处在于完全不用 LLM——提取是确定性流水线：两个微调编码器（约 130MB ONNX）在本地毫秒级完成显著性评分。无 API 调用，无 token 消耗，数据不离开本地，支持 SQLite WAL 和 FTS5 检索。

NoWreck：AI 编程助手的确定性验证器

#AI编程 #代码验证 #静态分析 #幻觉检测 #CLI工具 · 来源：GitHub

NoWreck 是一个 CLI 工具，验证 AI 编程助手的变更声明是否与实际代码修改一致。AI 工具的解释可能错误：引用不存在的函数、声称调用了未调用的 API、遗漏实际修改。NoWreck 用 AST 静态分析独立验证，而非依赖另一 AI。支持验证新增/删除函数、类、文件及函数调用共七种声明。免费模型也能准确识别 AI 声称调用 sanitize_input() 但实际未调用的情形。

推荐理由：NoWreck 用 AST 结构分析而非 AI 评判来验证 AI 编码修改的真实性，能精准识别幻觉函数和虚假声明，填补了 AI 编码信任验证的关键空白。
