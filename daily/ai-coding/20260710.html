中国警告 Anthropic Claude Code 存在安全后门漏洞

#Anthropic #Claude Code #安全 #地缘政治 #AI编程 · 来源：Channel News Asia

中国网络安全监管机构于7月8日发布警告，指出美国AI公司Anthropic的编程工具Claude Code存在安全后门，可能在未经用户同意的情况下向Anthropic服务器传输敏感信息，包括用户位置和身份识别符。中国监管机构提醒用户谨慎使用该工具。Anthropic随后回应称这是历史版本中的日志功能，已在后续版本中加强缓解措施，并承诺在次日版本中完全回滚这一功能。这是中国首次对主流AI编程工具发出安全警告，反映了AI编码工具在不同监管辖区面临的地缘政治风险。对使用Claude Code的企业和个人开发者而言，建议检查工具版本并关注Anthropic的后续安全公告。

推荐理由：中国监管机构首次对主流AI编程工具发出安全警告，直接影响使用Claude Code的企业安全策略。所有AI编程工具用户都应关注此事对工具选择和安全政策的影响。
