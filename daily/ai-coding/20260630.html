Cognition 发布 FrontierCode：首个评估代码合并质量的 AI 编码基准

#AI基准 #代码质量 #Cognition #SWE-bench #代码合并 · 来源：news.ycombinator.com

Cognition 推出 FrontierCode 基准，首次评估 AI 生成代码的「可合并性」——即代码是否会被人类维护者实际接受，而非仅测正确性。由 20+ 开源维护者从 36 个仓库构建任务，每个任务代表 40+ 小时工作量。采用六维度评估（行为正确性、机械整洁度、反向测试正确性、代码范围、代码质量、复杂正确性），假阳性率比 SWE-Bench Pro 低 81%。当前 Claude Opus 4.8 在最难的 Diamond 级别仅得 13.4%。

推荐理由：这是 AI 编码评估标准的重要升级。建议关注 FrontierCode 的评估维度，它们反映了企业级代码审查的真实标准。团队可参考其评估方法论优化 AI 代码生成流程。

干净的 GitHub 仓库欺骗 AI 编码代理执行恶意软件

#AI安全 #代码注入 #DNS攻击 #Claude Code #安全审计 · 来源：news.ycombinator.com

Mozilla 0DIN 研究人员展示了一种新型攻击：看似正常的 GitHub 仓库可以通过三步攻击链让 Claude Code 等 AI 编码工具执行恶意代码。攻击利用仓库中的「正常错误」→引导运行修复命令→通过 DNS TXT 记录获取远程命令执行。整个过程对人类审查者和安全代理完全不可见，因为恶意负载不在仓库代码中。

推荐理由：安全警示：使用 AI 编码代理时必须审查其执行的每一步操作。建议：1）要求代理披露完整的执行链；2）在沙箱环境中运行新项目初始化；3）监控代理的网络请求和 DNS 查询。

#Rust #代码清理 #AI代码质量 #Agent技能 #代码审查 · 来源：news.ycombinator.com

推荐理由：对使用 AI 编码代理的 Rust 项目非常实用。该技能的核心理念——「清理而非修复」——同样适用于其他语言。建议在 AI 生成代码的 MR/PR 流程中加入类似的审查步骤。
