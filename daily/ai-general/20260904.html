OpenAI 正式发布 Astra：号称迄今最强、最具争议的新模型

#OpenAI #Astra #模型发布 #AGI #安全 · 来源：

OpenAI 于周四发布新一代旗舰模型 Astra，官方称其在计算机与浏览器使用上开创'新前沿'，具备更快的速度、更高的准确性与安全性。Astra 将在一周内逐步向 Pro、Plus、Enterprise 等付费用户及 API 开放。OpenAI 总裁 Greg Brockman 称这是'迄今最智能也最对齐的模型'，并在软件工程基准上自称'迄今最佳编码模型'。该模型的争议点在于采用 opaque recurrence（不透明循环推理）技术，可能遮蔽可审计的思维链过程；首席科学家 Jakub Pachocki 回应称随着模型能力增强，可监控性正变得更难。Brockman 还表示随着与微软合同中 AGI 条款的取消，AGI 已从契约概念演变为'使命概念'，他个人认为'我们已经到了'。

推荐理由：OpenAI 新一代旗舰模型发布是本周最重要的 AI 事件，涉及模型能力、安全监控与 AGI 定义之争，影响面覆盖开发者与政策讨论。

英伟达确认以 129 亿美元收购 Hugging Face，承诺保持开放生态

#英伟达 #Hugging Face #并购 #开源生态 · 来源：

英伟达正式确认以 129.3 亿美元收购 AI 模型托管平台 Hugging Face，结束了持续数周的传闻。Hugging Face 平台目前托管约 300 万个模型、100 万个应用与 50 万个数据集，服务超过 1800 万开发者。英伟达 CEO 黄仁勋在博客中承诺，Hugging Face 将继续支持开源与开放权重模型，开发者仍可自由选择模型、框架、云与推理服务商，'英伟达算力并非使用 Hugging Face 的必要条件'。Hugging Face CEO Clem Delangue 表示，为在更大规模上成为闭源 API 的替代方案，需要更多算力与协作，因此选择与黄仁勋合作。该公司 2023 年完成约 3.95 亿美元融资，当前年化收入据报约 1.5 亿美元。

#分布式训练 #预训练 #算力 #Templar · 来源：

Templar Research 发布分布式预训练平台 Crucible，并公布首次端到端运行结果：用分布在多个云与区域的 48 块 A100 GPU 完成 8B 模型 505.3 亿 token 的预训练，估算成本为每百万 token 0.1202 美元，即便计入低带宽通信带来的吞吐损失，仍比集中式 AWS A100 集群（按 Capacity Blocks 挂牌价估算约 0.1686 美元/Mtok）低约 29%。系统结合 SparseLoCo（跨副本用 1-3% 稀疏 2-bit 伪梯度同步，压缩率最高 171 倍）、基于子空间网络的低带宽流水并行与流式重叠通信，实测端到端 MFU 为 48.3%。团队此前曾用类似方法在互联网级低带宽环境下训练出 72B 参数的 Covenant-72B。论文称这是业界首次在真实系统上证明全球分布式预训练在计入网络开销后仍具成本竞争力。
